# Patterns

Recurring shapes that work across tools and models. Each pattern here is a way of organizing context that has earned its keep on real problems.

Pattern pages will be filled in as the catalog grows. Candidates currently in the queue:

- **Scope by directory** — let the file system carry the layering
- **Layered context** — global → project → task, with overrides
- **Role + task + constraints** — the three-part frame for system prompts
- **Retrieve before generate** — when to add a retrieval step instead of stuffing context
- **Cite, don't summarize** — when to point at a file vs. paraphrase it
- **Negative examples** — using counter-examples to define behavior
